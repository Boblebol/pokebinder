# Code of Conduct

This project should be a practical and respectful place to collaborate.

## Expected behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections when something causes harm.
- Keep criticism focused on code, documentation, design, or project decisions.
- Prefer clear technical reasoning over sarcasm or personal remarks.
- Respect maintainers' time by keeping issues and pull requests focused.

## Unacceptable behavior

- Harassment, threats, insults, or discriminatory language.
- Publishing private information without permission.
- Repeated off-topic comments after a maintainer asks to stop.
- Bad-faith reports, spam, or intentionally disruptive behavior.

## Enforcement

Maintainers may edit, hide, or remove comments and may block contributors who violate this code of conduct. Enforcement decisions should be proportionate to the behavior and focused on keeping the project usable for contributors.

If you need to report a conduct issue, contact the repository owner through GitHub.
